POTATO QUIZ READ ME

I am inspired by buzzfeed quizzes that are usually food related and wanted to make a WHAT KIND OF POTATO ARE YOU quiz.

Everyone has to have at least one potato dish they have close to their heart. I wanted to make a really hyperspecific quiz with a ton of options to determine what the player's type of potato was. I had some difficulty getting it to store the last result of the options and implementing a point system for the quiz aspect, so I kind of took a simpler approach with each question option being attached to one type of potato. It's a bit obvious I feel like for the options on which potato option it pertains to, but whateverrr. I have it set so that if there is a tie of points for each potato variant, it will randomly choose one of the potatoes that was tied. Also I'm an idiot and realized I didn't use localStorage so I used it to record other players results and create like a potato leaderboard.

The design of the quiz visually is pretty simple, and I think if I had more time I would make it cuter and suit my website more? And even draw the potato icons out.
